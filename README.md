# Machine Learning

A comprehensive collection of Python notebooks and code examples for learning machine learning concepts and techniques.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/talhaghauridev/learn-machine-learning.git
cd learn-machine-learning
```

### 2. Create Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate Virtual Environment

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS/Linux:**
```bash
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```
